## Removing Optional Microsoft Apps

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\winbloat.ps1"
```

Removes typical preinstalled apps:

- Bing News/Weather/Search
- Get Help
- Get Started
- Office Hub
- Solitaire
- Maps
- Phone Link
- Teams
- Clipchamp
- Media players and other optional components

Microsoft Store, Edge, and essential system apps remain untouched.

***

## Удаление необязательных приложений Microsoft

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\winbloat.ps1"
```

Удаляет типичные предустановленные приложения:

- Bing News/Weather/Search
- Get Help
- Get Started
- Office Hub
- Solitaire
- Maps
- Phone Link
- Teams
- Clipchamp
- медиаплееры и другие необязательные компоненты.

Microsoft Store, Edge и основные системные приложения не затрагиваются.
